# Historical diagram assets

All existing exported diagrams in this directory are historical design references.
Their filenames, including “current”, do not indicate current authority.
Preserve originals/source vectors; no diagram proves wiring, selected parts or test results.

was updated in previous chats, but its historical exports are not synchronized evidence.

and [ADRs](../../docs/architecture/decisions/README.md) for implementation.
